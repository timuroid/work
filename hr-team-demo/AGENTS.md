# Инструкции для агента

1. Для вопроса сотрудника открой [HR-карту](knowledge/README.md) и примени [скилл ответа](skills/hr-answer/SKILL.md).
2. Для сводки руководителю прочитай [статус проекта](projects/onboarding/STATUS.md) и примени [скилл сводки](skills/project-brief/SKILL.md).
3. Проверяй, какой документ действовал на дату вопроса. Указывай путь к файлу и раздел. Если сведений не хватает, напиши, у кого их уточнить.
4. Во время учебных вопросов читай файлы этой папки. Сохраняй их без изменений до отдельной команды на правку.
