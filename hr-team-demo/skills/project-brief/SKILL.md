# Сводка по проекту

1. Прочитай `projects/onboarding/CONTEXT.md`, `STATUS.md` и `DECISIONS.md` внутри папки проекта.
2. Раздели подтверждённые решения, открытые вопросы и следующий шаг. Проверь каждое решение по источнику в журнале.
3. Для открытого вопроса назови ответственного по роли и ожидаемое действие.

Формат: три коротких блока «Решено», «Открыто», «Дальше» со ссылками на файлы.
